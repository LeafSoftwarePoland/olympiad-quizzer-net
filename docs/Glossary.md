# Glossary

Project-specific terms. The `docs/` glossary is the authoritative reference. Do not duplicate it in pipeline artifacts.

| Term | Full form | Explanation |
|------|-----------|-------------|
| OIJ | Olimpiada Informatyczna Juniorów | Polish national junior informatics olympiad. Main content source for this app. |
| VEA | Voivodeship Educational Authority | Wojewódzkie Kuratorium Oświaty. Regional educational authorities (Śląskie, Dolnośląskie, etc.) that run their own informatics competitions. |
| MEA / MEN | Ministerstwo Edukacji Narodowej | Main Educational Authority. National-level education ministry. |
| WASM | WebAssembly | Runtime format used by Blazor WASM frontend. Runs in browser without plugins. |
| ADR | Architecture Decision Record | A document capturing a single architectural or product decision and its rationale. See `docs/adl/`. |
| ADL | Architecture Decision Log | The collection of all ADRs. See `docs/adl/INDEX.md`. |
| POC | Proof of Concept | A time-boxed experiment to validate a technical assumption. See `docs/pocs/`. |
| Etap | Stage (Polish) | Competition round. E1 = Etap I (school), E2 = Etap II (district), E3 = Etap III (national). |
