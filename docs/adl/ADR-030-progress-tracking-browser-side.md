# ADR-030: Progress and history tracking — browser-side, lost on cache clear

**Status:** Shell
**Date:** 2026-08-12

## Problem

Students may want to track long-term progress: which questions they answered correctly, how many attempts, score history over time. Without user accounts (ADR-015), this data can only live in the browser (localStorage or IndexedDB). localStorage data is lost on cache clear, private browsing, or device change. No decision has been made about whether to implement this, what the UX is, or how to communicate the data-loss risk to users.
