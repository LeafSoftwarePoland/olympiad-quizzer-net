# Glossary — olympiad-quizzer-net

| Term | Definition |
|---|---|
| OIJ | Olimpiada Informatyczna Juniorów — national algorithmics olympiad for primary school students |
| VEA | Voivodeship Educational Authority (Kuratorium) — organizes regional IT subject competitions |
| Konkurs przedmiotowy | Subject-area competition run by voivodeship kuratoria |
| ContentBlock | Discriminated union: TextBlock / CodeBlock / ImageBlock — matches py-pdf-scraper output |
| QuizMode | ContestSimulation (timed) or FreePractice (untimed, topic-based) |
| POC | Proof-of-concept — 1 mock question per type, proves full stack end-to-end |
| WASM | WebAssembly — Blazor WASM compiles C# to run in browser, no server required |
| py-pdf-scraper | Companion Python project that extracts questions from PDFs into combined.json |
| source | Enum: oij / vea / other — identifies question origin |
