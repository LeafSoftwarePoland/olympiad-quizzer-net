This project contains all domain types, grading logic, and serialization contracts for the quiz application. It defines `Question`, `QuestionType`, `SubmittedAnswer`, `GradeResult`, `QuizSessionState`, and the interfaces that outer layers depend on. The domain has no dependencies on infrastructure, ASP.NET Core, or any I/O mechanism. `Grader` scores submitted answers against correct answers for all question types. `JsonOptions` holds the shared serializer configuration that both the API and the client must use consistently.
