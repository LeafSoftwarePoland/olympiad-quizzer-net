This project implements `IQuestionRepository` by reading a JSON question bank file from disk at startup. `QuestionBankLoader` reads and validates the file once; `JsonQuestionRepository` filters and shuffles the loaded questions on each request. The Fisher-Yates shuffler is the production implementation; a seeded variant is provided for deterministic L1 tests. This project depends on `olympiad-quizzer-net.Core.Domain` and registers its services via `AddQuestionBankInfrastructure`.
