This project is the Blazor WebAssembly client that runs in the browser. It fetches questions and filter options from the API, presents quiz sessions to the student, and grades answers locally using the shared domain logic from `olympiad-quizzer-net.Core.Domain`. Session state is persisted to `localStorage` with strict validation on load to prevent tampered data from reaching application logic. All user-facing text is in Polish; all identifiers and file names are in English.
