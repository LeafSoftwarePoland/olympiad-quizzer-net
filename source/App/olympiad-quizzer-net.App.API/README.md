This project is the ASP.NET Core Minimal API host that serves question and filter data to the Blazor client. It exposes three endpoints: `GET /api/questions`, `GET /api/filters`, and `GET /healthz`, plus a `robots.txt` route. Startup wires the CORS policy, shared JSON serialization options, and the infrastructure services from `olympiad-quizzer-net.Infrastructure.SQLite`. The question bank is warmed at startup so a broken deploy fails the health check rather than the first student request.
